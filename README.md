# BTC 灵动岛：Scripting 手动刷新版

## iPhone 上配置

1. 在 Scripting 中创建脚本项目，命名为 `BTC灵动岛`。
2. 将 `index.tsx` 的内容替换成同名文件的代码。
3. 在同一个脚本项目中新建 `live_activity.tsx`，粘贴同名文件的代码。不要把两个文件合并。
4. 保存两个文件，然后运行 `index.tsx`，选择“开始显示 / 刷新价格”。
5. 允许系统请求的实时活动权限，返回主屏幕查看；长按灵动岛查看精确价格、24 小时涨跌幅和行情时间。
6. 再次运行脚本可以刷新，或选择“停止显示”。应用创建的 `script.json` 无须手动替换。

## 行情与限制

- 只读取 OKX 的公共 BTC/USDT 现货行情，不连接账户，不需要钱包、API 密钥或交易权限。
- 灵动岛紧凑模式显示四舍五入后的整数价格；展开和锁屏显示两位小数。单位是 USDT，不是美元现金。
- 本版本没有自动轮询、后台保活或推送服务。切出应用后，价格不会自动刷新。
- 状态携带行情时间，更新两分钟后标记为 stale；界面仍明确标注“手动刷新”，避免误认为实时行情。
- 网络失败不覆盖上一份报价。接口返回超过五分钟的旧行情时，拒绝更新。
- 停止只针对本脚本保存的活动 ID，不调用“结束全部实时活动”，避免影响其他脚本。
- iOS 会调度灵动岛展示；有其他实时活动时，可能只显示 ₿ 图标。实时活动最长持续时间受系统限制。
- 公共行情源在你的网络上可能不可达。若报网络错误，请提供错误文字或截图，不要提供账号密钥。
- 创建活动成功后会保留在系统中，脚本退出不会让价格继续自动更新。

## 验证边界

代码依据 Scripting 官方 LiveActivity、Dialog、Storage、fetch 文档编写。公共行情接口已从开发环境请求验证，但开发环境没有连接你的 iPhone；实际权限、界面布局、Scripting 版本兼容性以及国行设备网络可用性仍需真机验证。
